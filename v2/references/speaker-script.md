# Speaker Script Guide

Only generate this artifact in `full` mode or when the user requests a script.

## Baseline speaking rates
Use these as planning ranges, not rigid guarantees:
- Japanese: roughly 300–340 characters/minute for a technical presentation.
- Chinese: roughly 220–260 Chinese characters/minute.
- English: roughly 130–150 words/minute.

Adjust for demos, pauses, Q&A, non-native delivery and dense technical terminology.

## Recommended structure
1. Metadata: deck version, target duration, audience, presenter.
2. Timing matrix: slide number, topic, target duration, cumulative time.
3. Per-slide script with time range and clear `[NEXT SLIDE]` cues.
4. Emphasis cues only for truly important engineering terms; do not bold every specification.

The script should sound natural when spoken. Do not simply read all slide text aloud.
