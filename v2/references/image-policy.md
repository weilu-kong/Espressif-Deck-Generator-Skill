# Image Policy

## Priority
1. Official Espressif product imagery.
2. Official module/development-board imagery.
3. Official partner/standard-body imagery where relevant.
4. Clearly labelled illustration/concept if no official visual exists.

## Rules
- Never use another product as an unlabeled substitute.
- Never present AI-generated concept art as an official product photo.
- Preserve aspect ratio with `object-fit: contain` for hardware.
- Avoid cropping antennas, connectors, board edges or package markings when those are meaningful.
- For comparisons, use the same class of visual evidence.
- Store local reusable images in a project `images/` folder and use relative paths.
- Add useful `alt` text.

## Copyright / branding
Use materials consistent with their published usage terms. For external standards logos and certification marks, follow the applicable brand guidelines rather than approximating the mark yourself.
