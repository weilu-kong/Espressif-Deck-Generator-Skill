# Slide-by-Slide Technical Explanation / Q&A Guide

Only generate when the user needs presenter enablement, FAE handoff or customer Q&A preparation.

For each slide include:
- What is shown: title, products, diagrams and visual evidence.
- Narrative role: why this slide exists and how it connects to the previous/next slide.
- Verified technical facts: cite the exact authoritative source/revision when available.
- Boundaries and caveats: preliminary status, feature limitations, certification scope, benchmark conditions.
- Customer discussion points: concrete engineering value rather than generic marketing claims.
- Likely Q&A: concise answer plus source/limitation.

Do not repeat unsupported numbers from the slide. If a fact cannot be verified, explicitly mark it for verification rather than inventing an answer.
