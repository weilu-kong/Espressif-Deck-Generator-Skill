# Branding assets

V2 uses the official Espressif horizontal logo lockup rather than reconstructing the mark with CSS shapes or a substitute font.

Included variants:
- `espressif-logo-dark.svg`: red mark + white wordmark for dark slides.
- `espressif-logo-white.svg`: all-white lockup for the Espressif-red cover.

Source: Espressif's public `espressif/esp-faq` repository, `docs/_static/espressif-logo.svg`. The renderer embeds these SVGs as data URIs so generated decks do not depend on an external logo file.

Do not stretch, recolor, rotate, outline, or separate the logo mark and wordmark. Keep clear space around the lockup and follow Espressif's current logo guidelines for customer-facing material.
